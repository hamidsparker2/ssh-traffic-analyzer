# راهنمای فارسی

این مخزن ابزاری پایتونی برای مشاهده بخشی از فراداده‌های شبکه در یک سرور لینوکسی و تولید گزارش JSON است.

## فایل‌ها

- `README.md`: معرفی پروژه و محدودیت‌های فنی
- `user_monitor.py`: اسکریپت پایش
- `docs/setup-and-usage.md`: راهنمای راه‌اندازی، اجرا و تحلیل JSON
- `LICENSE`: مجوز پروژه، در صورت انتخاب و افزودن
- `.gitignore`: جلوگیری از ثبت فایل‌های حساس و خروجی‌های محلی در Git

## هشدار درباره دقت

این ابزار زمان تعامل واقعی با صفحه یا اپلیکیشن را اندازه نمی‌گیرد. خروجی آن بر اساس اتصال‌ها و نشانه‌های شبکه تخمین زده می‌شود و ممکن است ترافیک پس‌زمینه یا ترافیک متعلق به حساب‌های دیگر را نیز ببیند. گزارش‌ها را به‌عنوان داده حساس نگه دارید و از ابزار فقط با مجوز و رضایت لازم استفاده کنید.

برای راهنمای کامل اجرا و پرامپت انگلیسی تحلیل گزارش، به [Setup and Usage](../setup-and-usage.md) مراجعه کنید.
